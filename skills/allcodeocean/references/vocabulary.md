# Vocabulary (EN glossary, compact)

- **Ocean**: the single shared environment. **Lagoon**: closed organizational circuit. **Bridge**: selective exchange lagoon↔Ocean. **Currents**: movement of fragments (Kademlia + gossip).
- **Fragment / plankton**: smallest reusable unit with interface, contracts, hash, tags, reputation, resource profile. **Schools of fish**: functions/modules. **Islands**: packages/apps. **Ecosystems**: stacks. **Whales/reefs**: libraries.
- **Assembly**: subset S⊆ℱ with composition ∘ forming program p. **Φ**: objective α·Err+β·cost+γ·incomp. **Anchor references** (`ref`, `multi_ref`, `transform`): pointers to existing fragments inside an assembly.
- **Swarm / Agent**: many narrow executors; **Coordination**: sequential part limiting parallelism (Amdahl).
- **Zero excess**: carry nothing unused; MDL heuristic, not K(x). **MDL**: Rissanen 1978.
- **Reputation**: executable-test history + resource profile on a citation graph. **Stake**: economic bond at publication, slashed on detected maliciousness. **Queue-of-rights**: immutable rights history in a CRDT ("law in code").
- **Garbage flood**, **Verifier races**, **Compromise**: named risks (mitigations: stake, reference test suites + PBFT on results, locality of compromise).
- **Epistasis** (fragment interaction, parameter λ), **GDC sizing** (Goldberg–Deb–Clark population size), **Schema theorem ≠ convergence guarantee**, **No Free Lunch**.
- **Defensive prior art**, **Two-date chain**, **Working materials**, **Legal standing**: see legal-and-provenance.md.
- **Sedimentary layers**: all versions retained for audit/reuse.

Glossary quirks (RU vs EN): RU glossary had 44 terms vs EN 49 after fixes (parity gap, unresolved); EN has near-duplicate entries (Zero Excess ×2, Lookup vs Kademlia DHT).
