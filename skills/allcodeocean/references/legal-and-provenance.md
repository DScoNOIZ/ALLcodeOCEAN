- Publication terms on site: CC0 1.0 Universal; inalienable authorship (RF Civil Code arts. 1265/1267); "defensive prior art"; author "not operator / not beneficiary / not founder"; triple dating (DOI, OpenTimestamps, notary) "in preparation".
- **Two-date chain**: internal fixation 2026-10-26 via the public GitHub repo. Git commit dates are author-settable; stronger evidence = push events, Wayback snapshots, OpenTimestamps/DOI.
- **Caveats on prior art**: it only helps against later patents on what is *enabled* by the disclosure; a high-level description may not block implementation patents; "no one can patent what is disclosed" overclaims. Ideas are generally not protected by copyright (RF Civil Code art. 1259 excludes ideas/concepts/methods; verify). The concept also is not novel (Armstrong 2011, Unison, etc.), so it cannot be claimed as new.
